## Controles revisados

| Amenaza | Control | Veredicto |
|---|---|---|
| Gemini declara falsamente que un plan cumple | El evaluator ignora ese claim y verifica typed constraints | cerrado en el boundary |
| Output con campos inválidos | parser tipado, rangos y máximo de 8 candidatos | cerrado |
| Intervalo vacío | `endMinute > startMinute` obligatorio | cerrado |

| Gemini devuelve candidatos que inyectan instrucciones | drafts son datos; no se ejecutan como instrucciones | cerrado para L3 |

| Reintento o doble click | endpoint tiene comando acotado, pero no idempotency key específica | abierto |
| Dos descubrimientos concurrentes | revisión del snapshot y actualización condicional | cerrado contra stale write; puede generar dos lotes válidos |
| Candidatos inexistentes o desactualizados | provenance `gemini`; no se presentan como verificados | riesgo de producto aceptado |

## Mutación observada

Se cambió deliberadamente la comparación de intervalo de `<=` a `<`. El test de intervalo vacío falló; la mutación fue revertida.

## Veredicto

L3 es defendible como descubrimiento de sugerencias evaluadas, no como búsqueda factual de lugares. El siguiente nivel que agregue fuentes externas deberá introducir normalización y provenance de cada API antes de tratarlas como evidencia.
