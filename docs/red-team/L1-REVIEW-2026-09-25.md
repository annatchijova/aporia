## Threat model

El cliente, los inputs, los retries, las revisiones stale y las respuestas del provider son no confiables. El atacante puede modificar el bundle, repetir comandos, enviar JSON inválido o intentar cruzar rooms. No puede modificar el Worker server-side ni leer secretos del environment dentro de este alcance.

## Hipótesis abiertas

### H1 — Gemini structured output puede divergir del schema asumido

**Nivel:** PLAUSIBLE HYPOTHESIS.
**Predicción:** respuestas con campos omitidos, nulls, enum nuevo o `participantId` ambiguo deben permanecer pending/invalid y nunca confirmar un fact.
**Prueba pendiente:** fixture real de Gemini y respuestas adversariales; requiere API key server-side.

### H2 — Un crash entre writes puede romper atomicidad

**Nivel:** PLAUSIBLE HYPOTHESIS.
**Predicción:** D1 `batch` deja evento y snapshot ambos persistidos o ninguno; no aparece una revisión parcial.
**Prueba pendiente:** fault injection en runtime/SQLite y concurrencia real.

### H3 — La capability de sesión necesita límites operativos adicionales

**Nivel:** PLAUSIBLE HYPOTHESIS.
**Predicción:** una sesión aleatoria permite sólo el scope de su room; no se puede usar contra otra room ni para administrar capacidades no implementadas.
**Prueba pendiente:** matriz actor × room × operación con cliente modificado.

### H4 — Realtime no forma parte de L1

**Estado:** decisión consciente, no bug.
**Razón:** Webflow documenta streaming HTTP, pero no se confirmó WebSocket/SSE durable en el environment. L1 usa snapshots HTTP; agregar realtime sin prueba rompería la honestidad del producto.

## Gate para considerar L1 completo

L1 no debe declararse completo sólo por build local. Falta ejecutar, en el environment real:

1. migration y binding D1 remotos;
2. secret canario de Gemini sin exposición en bundle, logs, URLs o responses;
3. una extracción real que produzca propuesta pending;
4. confirmación y edición con provenance completa;
5. dos requests concurrentes con revisión stale;
6. recuperación desde un snapshot después de reinicio;
7. smoke test público desde la URL desplegada.
