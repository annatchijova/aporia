# APORIA demo script

## 90-second path

1. Open the public room URL and create a room in Spanish.
2. Add a name and a planning goal such as `Cena después de Nerdearla`.
3. Paste a messy constraint: `Puedo el sábado después de las 20, pero no quiero gastar más de 25.000 ARS.`
4. Click **Extraer condiciones**. Explain that Gemini only proposes.
5. Select the participant if needed and click **Confirmar**. Explain that only confirmation enters the canonical model.
6. Add a real candidate manually, or click **Descubrir opciones**.
7. Review Gemini's suggested candidates and click **Aceptar estas opciones**.
8. Point to the deterministic result: **Funciona** or the exact reason it does not.
9. If every candidate fails, click **Buscar el cambio mínimo** and show the budget/time concession.
10. Switch English and dark mode only if there is time; they are supporting UX, not the product's core proof.

## What to say

> APORIA separates interpretation from decision. Gemini reads messy human input and proposes structure. People confirm it. Then APORIA's deterministic engine checks the plans and explains what would have to change when nothing fits.

## Honest boundary

Screenshots are bounded to PNG, JPEG, and WebP up to 1.5 MB. Gemini suggestions are not verified facts or live venue data. A public deployment must have its D1 migrations applied and its Gemini secret configured server-side before this flow is presented as live.
